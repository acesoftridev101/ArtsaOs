ArtsaOS



ArtsaOS is an experimental 32-bit x86 operating system written in C++.



Features

Multiboot 1 boot support

GRUB bootloader

VGA text-mode console

PS/2 keyboard input

Interactive command interpreter

Basic system information

Reboot and CPU halt commands

Architecture

Language: C++

Architecture: x86 32-bit

Bootloader: GRUB

Boot protocol: Multiboot 1

Status


ArtsaOS is currently an experimental hobby operating system under development.



Roadmap

Memory management

Interrupt handling

Graphical desktop

Mouse support

Filesystem

Application support



Warning: This project is experimental. Test it in an emulator such as QEMU before attempting to boot physical hardware.
